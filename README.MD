# Defensive-security archive

## Removed unsafe code

This repository no longer distributes keylogging, persistence, concealment, or data-exfiltration code.

Those techniques can harm users and are not appropriate for a public project. This repository is retained only as a reminder to review systems for unauthorized input-capture software and to remove it safely.

If you discover this type of software on a device, disconnect the device from networks, preserve evidence according to your organization’s incident-response process, run a trusted security scan, and rotate passwords from a separate clean device.
